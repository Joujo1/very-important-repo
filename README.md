# Project images

Put your five pictures in this folder with these exact names:

- project-1.jpg
- project-2.jpg
- project-3.jpg
- project-4.jpg
- project-5.jpg

Landscape pictures (4:3 or 16:9) look best. They are cropped to 4:3 automatically.
If your files are .png, rename them or change the file names in index.html.
Until a picture is added, the site shows a striped placeholder instead.
